# InfoConnect
Projeto de Prova de Aptidão Profissional (PAP) - Gestão de Suporte Técnico.

## Visão Geral
Plataforma Web Full-Stack para gestão de pedidos de assistência informática, orçamentos e comunicação entre clientes e técnicos.

## Requisitos
* Node.js
* XAMPP (MySQL)

## Configuração Rápida
1. Clone o repositório.
2. Crie um ficheiro `.env` na raiz (baseado no `.env.example`) com as credenciais da Base de Dados e SMTP Gmail.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o Servidor Backend:
    ```bash
    node server.cjs
    ```
5. Inicie o Frontend (em outro terminal):
    ```bash
    npm run dev
    ```
